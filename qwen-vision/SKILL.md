# Qwen Vision 图片内容分析

使用本地 Ollama 的 Qwen3 模型分析图片的视觉内容、场景、物体等。

## 触发条件

- 需要分析图片内容而非纯文字识别
- 用户发送图片要求"这是什么"、"分析图片"、"描述场景"等
- 需要识别物体、人物动作、场景氛围、图像风格等

## 使用方法

### 方式一：Ollama CLI（推荐）

```bash
ollama run qwen3:14b "描述图片中的场景和内容" "<图片路径>"
```

### 方式二：轻量模型（省显存）

```bash
ollama run qwen3:8b "简要描述这张图片" "<图片路径>"
```

## 参数说明

| 参数 | 说明 | 推荐模型 |
|------|------|----------|
| qwen3:14b | 高质量分析，细节丰富 | 复杂场景、深度分析 |
| qwen3:8b | 快速响应，占用显存少 | 简单描述、快速识别 |

## 常用 Prompt 示例

```bash
# 场景描述
ollama run qwen3:14b "详细描述这张图片的场景、人物、氛围" "photo.jpg"

# 物体识别
ollama run qwen3:14b "图片中有哪些物体？列出所有可见的物品" "room.png"

# 人物分析
ollama run qwen3:14b "描述图片中的人物：数量、性别、年龄、表情、穿着、动作" "people.jpg"

# 图像风格
ollama run qwen3:14b "这张图片是什么风格？照片还是AI生成？分析画面特点" "art.jpg"

# 新闻/事件
ollama run qwen3:14b "分析这张新闻照片的背景、人物身份、事件性质" "news.jpg"

# 简单描述（轻量）
ollama run qwen3:8b "一句话描述这张图片" "photo.jpg"
```

## 模型对比

| 模型 | 大小 | 显存 | 速度 | 质量 |
|------|------|------|------|------|
| qwen3:14b | 9.3 GB | ~10 GB | 较慢 | ⭐⭐⭐⭐⭐ |
| qwen3:8b | 5.2 GB | ~6 GB | 快 | ⭐⭐⭐⭐ |
| qwen2.5:7b | 4.7 GB | ~5 GB | 快 | ⭐⭐⭐ |

## 注意事项

- 首次调用需要加载模型，约 3-5 秒
- 热启动约 1-2 秒
- 如果显存不足，关闭其他 GPU 应用（如 Fooocus）
- 分析人物身份时结果可能不准确，建议结合搜索验证

## 与 GLM-OCR 的区别

| 场景 | 推荐工具 | 原因 |
|------|----------|------|
| 识别文字、文档、证件 | GLM-OCR | 专为文字优化 |
| 分析场景、物体、人物 | Qwen Vision | 通用视觉理解 |
| 表格、图表数据 | GLM-OCR | 保持格式结构 |
| 艺术风格、氛围 | Qwen Vision | 需要语义理解 |

## 错误处理

- **模型未找到**：先运行 `ollama pull qwen3:14b` 或 `ollama pull qwen3:8b`
- **显存不足**：使用 8B 模型，或关闭其他 GPU 应用
- **Ollama 未运行**：启动 Ollama 服务
